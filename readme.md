# Product Preview Card Component

A responsive product preview card built as part of the Frontend Mentor challenge.  
This project focuses on building a clean product UI using HTML and CSS with emphasis on layout, typography, and responsiveness.

![Product Preview Card](./screenshot.png)

---

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Variables
- Responsive Design
- Mobile-first workflow

---

## 📌 Features

- Clean product card layout with image and details section
- Responsive design for mobile and desktop screens
- Pricing section with discount styling
- Hover effect on call-to-action button
- Pixel-perfect UI based on design challenge
